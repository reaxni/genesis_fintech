# Подготовленные роли
Конфигурации подготовлены, но не установлены в служебную папку .codex: автоматическая проверка разрешений отклонила запись в неё.
Доступные в текущем чате subagents уже могут получать инструкции этих ролей от координатора через AGENTS.md. Это рабочий резервный вариант без изменения защищённой конфигурации.

Для клиента, поддерживающего custom roles, пользователь может самостоятельно разместить config.toml в .codex/config.toml, а каталог agents — в .codex/agents и открыть новую сессию.
Если там уже есть настройки, нужно объединить таблицы agents с сохранением чужих параметров, а не заменять файл целиком.
Агент не должен пытаться обойти запрет записи перемещением, ссылками или другим инструментом.
Модели не закреплены: наследуется выбор пользователя/родителя. Глобальная конфигурация не менялась.
Синтаксис и относительные ссылки проверяются локально; активация клиентом пока не проверена.
