# Проверка изоляции

Из корня репозитория на Ubuntu с Docker Compose:

```bash
bash sandbox/run_isolation_checks.sh
```

Скрипт использует опубликованный корпус. Он запускает исходные тесты в контейнере, прогоняет политики через Unix-сокет и проверяет сценарии C18–C20. Отчёты сохраняются в `artifacts/isolation/`. GitHub Actions запускает эту проверку отдельным заданием.

| Проверка | Результат на Ubuntu x86_64 |
|---|---|
| C18 · дедлайн | Зависшая политика остановилась через 60,03 с с пустыми findings. Медленная остановилась через 60,00 с после 39 шагов, тоже с пустыми findings. |
| C19 · награда | Все публичные награды в closed равны числовому 0. |
| C20 · контейнер политики | UID 65532, capabilities отключены, файловая система только для чтения. Сеть, Docker socket, файлы эпизода и модули оценщика недоступны. |
