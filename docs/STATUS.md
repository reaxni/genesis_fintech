# Состояние Genesis

Сборка подготовлена к отправке. В `main` добавлены генератор, среда, оценщик, 10 train и 10 dev эпизодов, Docker-запуск и документация. Полная проверка запускается командой `bash scripts/verify.sh`. GitHub Actions собирает архив `genesis-submission` из проверенного дерева и результатов этого запуска.
