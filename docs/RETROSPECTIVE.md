## 21 ноября — запуск роли C

При проверке команд обнаружились два разных имени проекта Compose. Отдельная сборка создавала образы под одним именем, а полный прогон с запретом загрузки ожидал их под другим. Теперь один скрипт собирает и запускает сервисы в одном проекте. Команда `bash scripts/verify.sh --container-smoke` проверяет этот путь для оценщика. В Linux она также запускает тест двух последовательных сеансов через Unix-сокет. Проверка контейнера настоящей политики остаётся частью интеграции с B.
